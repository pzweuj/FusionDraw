# FusionDraw

FusionDraw is a browser-first fusion diagram engine. Annotation lookup and rendering are deliberately separate: GTF is compiled into static annotation packs, while the renderer consumes only a resolved `FusionPlotSpec`.

## Development

```bash
pnpm install
pnpm dev
pnpm test
pnpm typecheck
```

`pnpm test` runs the TypeScript suite and the annotation compiler's Python
determinism/tag suite (`pnpm test:annotation`).

The demo includes small hg38 and hg19 fixtures so the complete Automatic → Advanced → SVG workflow works without a backend. Production packs are generated by `annotation-builder/build_annotation.py` and should be versioned through their manifest checksums.

Compiler-generated packs also record per-shard SHA-256 values. `StaticAnnotationProvider`
uses the manifest checksum as the Cache API namespace and verifies a shard before
using it, so a stale or corrupted cached response cannot silently enter a plot.

The exported `applyPlotExonEdit` helper is used by the demo editor to keep
biological coordinate overrides independent from visual label/width/visibility
changes. Clearing either coordinate removes the pair explicitly, allowing a
segment to become coordinate-free without falling back to the original exon.

Automatic resolution is terminal on annotation errors: the resolver returns
`errors` without `data`, so a caller can explicitly continue with a manual
PlotSpec instead of accidentally exporting a biologically invalid diagram.
Providers may expose pinned release metadata through `getMetadata`; the
resolver copies its source, annotation version, and pack checksum into
`PlotSpec.provenance`.
Editable fusion exons are stored independently from the source transcript;
biological edits live under `exon.biological`, while label/width/visibility
edits live under `exon.visual`. Breakpoint coordinates are 1-based inclusive;
when a breakpoint splits an exon, the 5′ segment keeps the breakpoint base and
the 3′ segment starts at the following transcript-direction base, avoiding
double coverage.

FusionDraw is intended for research and report illustration, not clinical diagnosis.
